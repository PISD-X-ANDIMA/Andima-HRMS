## 3. Yang baru

- **API D4 (14 route)**: `me`, `snapshot`, `kpi-catalog`, `performance-evaluations`, `kpi-assessments`, `competency-assessments`, `development-needs` (+ `/versions`), `training-records` (+ `/versions`). Kontrak lengkap di API-D4-001.
- **Keamanan**: semua request memakai sesi Supabase pengguna (tetap dibatasi RLS); semua `POST` hanya untuk HR dan MANAGER, peran lain mendapat 403.
- **Format error seragam**: `{ "error": { "code", "message" } }` dengan kode `BAD_REQUEST`, `UNAUTHENTICATED`, `FORBIDDEN`, `NOT_FOUND`, `VALIDATION_FAILED`, `INTEGRATION_ERROR`, `SERVER_ERROR`. Error 500 tidak membawa detail SQL.
- **Network & integration failure**: klien menampilkan pesan yang dapat dipahami untuk koneksi putus, timeout 20 detik, dan layanan data tidak terjangkau; simpan yang berhasil tidak dilaporkan gagal bila refresh data gagal.
- **Shell dan komponen bersama**: sidebar 6 menu, topbar dengan breadcrumb dan badge peran, tabel dengan pagination dan empty state, menu ⋮ langsung ke aksi, form modal berukuran tetap (640 / 880 px), toast, dan state loading/empty/error.
- **Detail dan History** selalu halaman sendiri dengan breadcrumb dan tombol Back (17 route).
- **Responsif**: konten sampai 1600 px; di bawah 1400 px kolom sekunder dashboard disembunyikan; di bawah 1024 px sidebar menjadi drawer.
- **Katalog KPI V5.1** (10 role × 5 KPI) dan migrasinya (belum diterapkan, lihat §7).
- **Seeder** `npm run seed:d4` (dry run default, `--apply` untuk menulis, data ditandai `[seed-d4]`).
- **Mode preview** fixture untuk pengembangan lokal saja (tidak aktif di build production).

## 4. Perubahan

- Form Performance Evaluation disederhanakan sesuai FR-D4-001: tujuh aspek, review status manual, dan Save Draft dihapus.
- KPI Scorecard: pilihan role manual diganti KPI jabatan otomatis; server menolak role yang tidak cocok dengan position.
- Perubahan status Development dan Training disimpan sebagai revisi baru, bukan menimpa record.
- Label status `Bukti Belum Cukup` ditampilkan sebagai **Data Belum Cukup** dengan warna netral.
- Label peran "HR Manager" menjadi "HR"; data contoh memakai nama placeholder.
- Type scale dan aksen hijau mengikuti D3.

## 8. Catatan deployment

1. Set environment: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `NEXT_PUBLIC_D4_DATA_MODE=supabase` (lihat `.env.example`; mode `fixture` diabaikan di production).
2. Terapkan migrasi `20260929150000_d4_kpi_catalog_v51.sql` setelah disetujui.
3. Opsional: `npm run seed:d4 -- --apply` untuk data demo bertanda `[seed-d4]`.
4. `npm run build`, deploy, lalu smoke test: login per peran (HR, MANAGER, EMPLOYEE), buka keenam menu, simpan satu record per fitur, cek 403 untuk EMPLOYEE.
